Account Tiers & Routing

All Standard (Free) accounts are provisioned with $1.00 in API credits upon creation. Credit consumption varies by usage, but this allocation is sufficient for meaningful exploration of the platform.

Model selection is handled automatically for Standard accounts — the platform routes requests to the most appropriate model for your prompt. To access specific models or unlock priority routing, upgrade your plan or top up credits.

Remember: API credits always get consumed first! Top up credits to choose your own models. Once topped up, you can explicitly request any premium model within CC or CX.

Claude Code (CC) Codex (CX) Custom IDEs (API)

Follow these precise steps to permanently configure the official Claude Code CLI to route its intelligence directly through the Inference proxy network.

  1. 1

    Obtain your API Key

    First, navigate to the API Keys page, generate a new access key, and copy it to your clipboard. This will act as your authentication token.

    Generate API Key
  2. 2

    Install & Initialize Claude

    If you haven't already, install Claude Code globally via npm. After it installs, run it once and immediately exit. This forces your OS to generate the hidden .claude configuration folder. 

    npm install -g @anthropic-ai/claude-code
claude
# Press Ctrl+C or type /exit to close it
  3. 3

    Modify settings.json

    Instead of exporting environment variables manually, you can set them globally in Claude's configuration file.

    Navigate to ~/.claude/settings.json and paste the following configuration: 

    {
  "env": {
    "ANTHROPIC_API_KEY": "YOUR_INFERENCE_API_KEY",
    "ANTHROPIC_BASE_URL": "https://api.inference.uno",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1"
  }
}

    Note: Replace YOUR_INFERENCE_API_KEY with your copied key. The base URL strictly targets the root port because Claude appends /v1/messages automatically.

  4. 4

    Launch Claude

    Start Claude Code as usual. Your requests will now securely tunnel through the proxy forever. 

    claude
